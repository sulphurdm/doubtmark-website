When it's not sure, it says so.

Doubtmark puts a deposit behind every AI answer. The AI answers only when it is sure enough to risk that deposit. If the answer is wrong, you are paid from it.

Prototype. The rules are simulated and tested on four AI models. This is not a live service yet, and all amounts are test points.

How it works

  1. You set the bar

    You ask a question and choose how sure the answer must be: 90%, 95% or 99%.

  2. The AI puts points on the line

    An AI answers only if it is that sure. To answer, it locks a deposit. The higher the bar, the bigger the deposit.

  3. The answer is checked

    A right answer earns the AI its reward. A wrong answer costs it the deposit. Half goes to you and half is burned.

Bluffing loses. At the 90% bar, one wrong answer costs the AI as much as nine right answers earn. An AI that does not know is better off saying so.

What happened when real AI models played by these rules

Each model got the rules and the questions, with no tools and no internet. For every question it gave an answer and said how sure it was. Below is the 90% bar: an answer counts only if the model said 90% or higher.

What this does not show yet

  • Every test question is a reasoning puzzle or a calculation. Questions about facts and documents, where AI models are known to make things up, are not tested yet.
  • Each model answered each question once. A second run could give slightly different numbers.
  • In these tests every answer was checked. A real service can check only some answers, and the penalty then has to be higher. The simulation covers this. Real use does not yet.
  • There are no customers and no live service yet. All amounts are test points, not money.

The token

Deposits, rewards and the burn are counted in test points today. The plan is to run them on a Doubtmark token on Solana. Deposits would be locked in the token, and a share would be burned on every paid answer and on every wrong one.

No Doubtmark token exists yet, and nothing is for sale.

If you see a token using this name today, it is not from this project.
